# ✨ Mood Lamp

A fun mood-based aura generator that changes colors, quotes, and vibes dynamically based on user emotions.

---

## ✨ Features

* Mood detection
* Dynamic background changes
* Aura-based color themes
* Mood quotes
* Emoji reactions
* Smooth transitions
* Aesthetic UI

---

## 🛠️ Tech Stack

* HTML
* CSS
* JavaScript

---

1. Clone the repository

```bash id="w8m2pr"
git clone https://github.com/roshninelson/mood-lamp.git
```
