# Mood Lamp 💡

An interactive RGB Mood Lamp that changes colors and lighting effects based on user interaction, environmental conditions, or predefined lighting patterns.

## 📖 Overview

Mood Lamp is a smart lighting project designed to create customizable ambient lighting using RGB LEDs and a microcontroller. The project demonstrates concepts from embedded systems, IoT, electronics, and user-centric design.

The lamp can generate different moods through dynamic color transitions, brightness adjustments, and lighting effects.

- 🎨 Multiple lighting modes
- 🔄 Smooth color transitions
- 💡 Adjustable brightness

## ⚙️ Installation

### 1. Clone the Repository

```bash
git clone https://github.com/roshninelson/mood-lamp.git
cd mood-lamp
```

### 2. Open the Project

Open the source code using:

- Arduino IDE
- PlatformIO
- VS Code (if applicable)

### 3. Upload the Code

1. Connect your microcontroller.
2. Select the correct board and port.
3. Upload the program.

## 🔌 Hardware Connections

| Component | Microcontroller Pin |
|------------|--------------------|
| Red LED | PWM Pin |
| Green LED | PWM Pin |
| Blue LED | PWM Pin |
| GND | GND |
| VCC | 5V / 3.3V |

> Adjust the pin numbers according to your hardware setup.
